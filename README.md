# Birthday Wish ❤️

A romantic birthday wish web app for my girlfriend. Built with pure HTML, CSS, and JavaScript — zero dependencies.

## Features

- **Loading Screen** — 3D gradient heart with realistic beating animation
- **Love Couplet** — Romantic Urdu poetry with a playful "Yes / No" interaction
- **Uncatchable "No" Button** — Dodges clicks by teleporting to random corners
- **Gallery** — Dual-image slideshow with slide-in animations (left: top→left, right: bottom→right)
- **Rose Petals** — Looping animated GIF overlay floating across all screens

## Hosting

Ready to deploy to Netlify — just connect this repo or drag the folder to [app.netlify.com/drop](https://app.netlify.com/drop).

## Customization

- **Photos**: Drop your images into `images/` and update the `PHOTOS` array in `script.js`
- **Quote**: Edit the poem text in `index.html`
